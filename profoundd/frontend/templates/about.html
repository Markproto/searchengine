How It Works

  1. Curated Sources - We crawl RSS/Atom feeds from vetted, verifiable sources (e.g., Reuters, PubMed, Nature, SCOTUSblog).
  2. Credibility Scoring - Each source is assigned a credibility score (1-10) that influences search rankings.
  3. Smart Ranking - Results are ranked by a combination of text relevance, source credibility, and recency.
  4. Transparent - Every result links directly to the original source. We don't host content; we help you find it.

Ranking Algorithm

Our search ranking considers:

  • Text Relevance (BM25) - How well the article matches your query
  • Source Credibility - Higher-credibility sources get a ranking boost
  • Recency - Recent articles (last 24h-7d) are boosted

Admins can adjust per-source weights through the admin panel.

API Access

Profoundd provides a free JSON API:

GET /api/search?q=your+query&category=news&page=1

Returns JSON with articles, total count, and pagination info.

Open Source

Profoundd is built with Python, Flask, Elasticsearch, and Scrapy. Designed to run on a single $6/month server.
