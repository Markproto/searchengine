Add Profoundd to Your Browser

Search Profoundd directly from your browser's address bar.

Brave / Chrome / Edge

  1. Visit profoundd.com a few times (the browser learns it supports OpenSearch automatically)
  2. Open Settings → Search engines (or type brave://settings/searchEngines)
  3. Find "Profoundd" in the list and click Make default

Or do it manually:

  1. Settings → Search engines → Manage search engines → Add
  2. Name: Profoundd
  3. Shortcut: profoundd.com or pf
  4. URL: https://profoundd.com/search?q=%s

Firefox

  1. Visit profoundd.com
  2. Right-click the address bar → Add "Profoundd"
  3. Go to Preferences → Search → choose Profoundd as default

Safari

Safari doesn't support adding custom search engines natively. Workaround:

  • Install the Smart Keyword Search extension, or
  • Bookmark https://profoundd.com/search?q= with a keyword like pf, then type pf followed by your query in the address bar

Why?

Using Profoundd as your default search engine means:

  • No Google ad profiles, no third-party trackers
  • Access to 1.3M+ Epstein court documents and 100K+ articles from independent sources
  • Source credibility scores visible on every result
  • Sponsored outlets (Pfizer etc.) clearly badged

Keyboard shortcut

Most browsers let you use a shortcut. If you set Profoundd's shortcut to pf, you can type:

pf epstein flight logs

in your address bar and go straight to Profoundd search results.
